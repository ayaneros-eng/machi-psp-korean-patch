거리 · 운명의 교차점 특별편 PSP 한글패치 R42
간편 적용판 / 적용 도구 개정 1

가장 쉬운 적용 방법

1. Machi_PSP_Korean_R42_Easy.zip을 마우스 오른쪽 버튼으로 누르고
   '압축 풀기' 또는 '모두 추출'을 선택합니다.
   ZIP 안에 보이는 파일을 직접 실행하지 마세요.

2. 압축을 푼 폴더에서 MachiPatch.exe를 더블클릭합니다.
   Python은 따로 설치하지 않아도 됩니다.
   MachiPatch.exe만 옮기지 말고 runtime 폴더와 나머지 파일을 함께 둡니다.

3. 'ISO 선택'으로 일본판 원본 ISO를 고릅니다.
   필요하면 '저장 위치'에서 결과를 저장할 폴더를 바꿉니다.

4. '한글패치 적용 시작'을 누르고 완료 안내를 기다립니다.
   결과 파일 이름은 Machi_R42_Korean.cso입니다.
   원본 ISO는 변경하지 않습니다.

기존 끌어놓기 방법

- 원본 ISO를 apply_patch.cmd 위에 끌어다 놓으면 적용창이 열리고
  ISO가 자동으로 선택됩니다. '한글패치 적용 시작'을 눌러 주세요.
- CMD를 더블클릭한 뒤 적용창에서 ISO를 선택해도 됩니다.
- CMD는 게임에서 나온 파일이 아니라 이 폴더의 apply_patch.cmd를 뜻합니다.

준비물

- Windows 10/11 64비트
- 일본판 원본 ISO: ULJM-05111 / 1,542,422,528바이트
- 여유 저장 공간 5GB 이상 권장
- 게임 ISO는 이 배포물에 포함되어 있지 않습니다.

잘 안 될 때

- '실행 환경 없음' 또는 파일 누락:
  Source code가 아닌 Machi_PSP_Korean_R42_Easy.zip을 받았는지 확인하고,
  빈 폴더에 전체 압축을 다시 풀어 주세요. 내부의 .patch.zip은 그대로 둡니다.
- 'ISO_SIZE' 또는 'ISO_HASH':
  지원하는 원본과 다른 파일입니다. 다른 판본, CSO, 이미 패치한 ISO는
  직접 적용할 수 없습니다. 파일명 변경이나 Python 재설치로 해결되지 않습니다.
- 'OUTPUT_EXISTS':
  같은 이름의 다른 파일이 있습니다. '저장 위치'에서 다른 이름을 지정하세요.
  정상적인 R42 결과가 이미 있으면 다시 만들지 않고 확인 완료로 안내합니다.
- 'SPACE': 공간을 확보하거나 다른 드라이브를 선택하세요.
- 'PERMISSION': 문서 또는 다운로드 등 쓰기 가능한 폴더를 선택하세요.
- 보안 프로그램이 차단하면 배포 출처와 파일 해시를 확인해 주세요.
  백신을 끄거나 격리된 파일을 무조건 복원할 필요는 없습니다.
- 오류가 계속되면 적용창의 '결과 메시지 복사'로 오류 코드를 전달해 주세요.
